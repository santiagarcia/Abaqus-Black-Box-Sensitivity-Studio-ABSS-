## 0. Notation and assumption ledger

| Symbol | Meaning |
|---|---|
| $i = 1..n$ | accepted increment index on the **frozen** nominal time grid $t_0 < t_1 < \dots < t_n$ (all steps concatenated) |
| $a$ | scalar parameter (a direction in parameter space for mixed derivatives, §4.6); $h$ = parameter offset |
| $u_i \in \mathbb R^N$ | **all** nodal DOF values at $t_i$ (free, prescribed and dependent), in the coordinates Abaqus prescribes (U, UR, …) |
| $q_i$ | all history Abaqus carries across increments: stresses, SDVs, plastic strains, contact state, stored reactions, … (opaque) |
| $r_i(u_i, u_{i-1}, q_{i-1}, a) = F^{ext}_i - F^{int}_i \in \mathbb R^N$ | incremental residual; $F^{ext}$ may depend on $u_i$ (follower loads) |
| $q_i = Q_i(u_i, u_{i-1}, q_{i-1}, a)$ | opaque history update (Abaqus constitutive/contact integration over $[t_{i-1}, t_i]$) |
| $u_i^*, q_i^*$ | nominal converged solution at $a$ |
| $R^{u}_i, R^{u'}_i, R^{q}_i, R^{a}_i$ | partial derivatives of $r_i$ w.r.t. $u_i, u_{i-1}, q_{i-1}, a$ at the nominal state (others held fixed) |
| $K_i = -R^u_i$ | tangent, structural positive sign |
| $s_i = du_i/da$, $w_i = dq_i/da$ | **total** derivatives along the equilibrium branch |
| $u_i^{(m)} = d^m u_i/da^m$ | $m$-th total derivative; $u_i^{(0)} = u_i^*$, $u_i^{(1)} = s_i$ |
| $F, C$ | free and prescribed DOF sets at increment $i$ (may change between steps); $g_i(a)$ prescribed values on $C$ |
| $I, D$ | independent and dependent DOFs of linear constraints $u_D = T u_I + g_D$ |
| $[h^m]\,f(h)$ | coefficient of $h^m$ in the Taylor expansion of $f$ at $h=0$ |
| RF | Abaqus reaction output; convention $RF = F^{int} - F^{ext} = -r$ on held DOFs **[H-RF]** |

Assumptions (each result lists which it uses):

- **A1 (frozen grid).** All branches use exactly the nominal $t_i$ and the same increment boundaries; no subdivision inside an oracle/commit increment. The derivative computed is the derivative *of the discrete algorithm on this grid*.
- **A2 (regularity $S_k$).** $r_i, Q_i$ are $C^{k+1}$ in a neighbourhood of the nominal trajectory (for an $O(h)$ first-order remainder: $C^2$). Excludes active-set switches inside the neighbourhood (§6).
- **A3 (solvability).** $K_{FF,i}$ (or the reduced $\hat K_{FF,i}$, §2.3) is nonsingular at every $i$. Then, by the implicit function theorem applied inductively over $i$, the branch $u_i(a)$ exists locally and is $C^{k+1}$ [exact].
- **A4 (oracle).** For any admissible prescribed $\tilde u$ and any committed history, the oracle returns $r_{F}(\tilde u, \text{history}, a)$ (reduced form with constraints) deterministically. This is the hypothesis **H-RF** of §3.
- **A5 (consistent tangent).** The supplied $K_i$ equals $-\partial r_i/\partial u_i$ of the discrete map. If not, §4.7 gives an oracle-only correction.

## 1. First order: the frozen-current-displacement pseudoload

### 1.1 Exact sensitivity equations [exact; A2 with k=1, A3]
Differentiate $r_i(u_i(a), u_{i-1}(a), q_{i-1}(a), a) \equiv 0$ and $q_i = Q_i(\cdot)$:

$$K_i s_i = p_i,\qquad p_i := R^a_i + R^{u'}_i s_{i-1} + R^q_i w_{i-1},$$
$$w_i = Q^u_i s_i + Q^{u'}_i s_{i-1} + Q^q_i w_{i-1} + Q^a_i,\qquad s_0 = du_0/da,\; w_0 = dq_0/da .$$

$p_i$ is the **total history-carrying pseudoload**: the total derivative of $r_i$ with the *current* displacement held fixed. $\partial_a r_i = R^a_i$ alone (the explicit partial) is not sufficient whenever there is history. ABSS never forms $Q^u, Q^q, R^q$; it obtains the whole of $p_i$ from one oracle difference.

### 1.2 Theorem 1 (pseudoload from a perturbed history branch) [exact asymptotics]
Let a branch for offset $h$ be defined by prescribed displacements $\tilde u_j(h)$ for $j < i$, with $\tilde u_0 = u_0(a+h)$, and its history generated by the oracle itself,
$\tilde q_j(h) = Q_j(\tilde u_j, \tilde u_{j-1}, \tilde q_{j-1}, a+h)$, $\tilde q_0 = q_0(a+h)$. Define
$$\mathcal D_i(h) := \frac{r_i(u_i^*, \tilde u_{i-1}(h), \tilde q_{i-1}(h), a+h) - r_i(u_i^*, \tilde u_{i-1}(0), \tilde q_{i-1}(0), a)}{h}.$$
If the branch is **first-order correct**, i.e. $\tilde u_j(h) = u_j^* + h s_j + O(h^2)$ for all $j<i$, then
$$\mathcal D_i(h) = p_i + O(h).$$
*Proof.* Lemma: $\tilde q_j(h) = q_j^* + h w_j + O(h^2)$. True for $j=0$; if true for $j-1$, a first-order Taylor expansion of $Q_j$ (C², A2) gives $\tilde q_j = q_j^* + h(Q^u s_j + Q^{u'} s_{j-1} + Q^q w_{j-1} + Q^a) + O(h^2) = q_j^* + h w_j + O(h^2)$. Then expand $r_i$ about the nominal point with $\delta u_i = 0$, $\delta u_{i-1} = h s_{i-1} + O(h^2)$, $\delta q_{i-1} = h w_{i-1} + O(h^2)$, $\delta a = h$: the numerator is $h(R^{u'} s_{i-1} + R^q w_{i-1} + R^a) + O(h^2)$. ∎

Remarks.
1. The constant in $O(h)$ is $\tfrac12 \tfrac{d^2}{dh^2}$ of the composite map $h\mapsto r_i(u_i^*,\tilde u_{i-1}(h),\tilde q_{i-1}(h),a+h)$; it includes the second-order history defect.
2. **Centred version** $\mathcal D^c_i = [r_i(+h) - r_i(-h)]/(2h) = p_i + O(h^2)$ with the same first-order branches at $\pm h$: the centred difference of any $C^3$ function of $h$ returns its $h$-derivative with $O(h^2)$ error, and that derivative depends on history only through first order [exact; checked: §7, D].
3. **Use the actual oracle value at $h=0$**, not 0, as the subtrahend. Abaqus converges only to tolerance, and $u^*$ may be rounded when written to the oracle input; the $h=0$ probe on a *nominal replay branch* (the branch machinery run with $h=0$) cancels both offsets exactly. Assuming $r_i(u_i^*,\text{nominal}) = 0$ adds an error $e_i/h$, where $\|e_i\|\le$ Abaqus residual tolerance — unbounded as $h \to 0$.
4. **With computed sensitivities** $\hat s_j \ne s_j$ (finite-$h$ errors), $\lim_{h\to0}\mathcal D_i = R^a + R^{u'}\hat s_{i-1} + R^q \hat w_{i-1}$, with $\hat w$ the $w$-recursion driven by $\hat s$. Errors therefore propagate exactly through the tangent-linear history recursion; accumulated error is bounded by the per-increment $O(h)$ (or $O(h^2)$ centred) error times the norm of that propagator, i.e. grows at most linearly in $n$ for a non-expansive history map.

### 1.3 Which branch to commit: predictor vs re-equilibrated [exact + checked]
Two first-order-correct choices for $\tilde u_j(h)$, $j<i$:

- **(P) Predictor branch:** $\tilde u_j = u_j^* + h \hat s_j$ prescribed on **all** independent DOFs (free and prescribed). History is generated by Abaqus with no global equilibrium iteration.
- **(E) Re-equilibrated branch:** $\tilde u_j = u_j(a+h)$, a full nonlinear Abaqus solve at $a+h$ on the frozen grid.

Both satisfy $\tilde u_j - (u_j^* + h s_j) = O(h^2)$ in exact arithmetic, so both give $\mathcal D_i = p_i + O(h)$. They differ in what they do with real solver tolerance: in (E) Newton stops at $\|r\|\le\tau$, so $\tilde u_j = u_j(a+h) + \delta_j$ with $\|\delta_j\| \lesssim \|K^{-1}\|\tau$, giving
$$\mathcal D_i^{(E)} = p_i + O(h) + O\!\big(\|[R^{u'}, R^q]\|\,\|K^{-1}\|\,\tau / h\big),$$
which does **not** converge as $h\to0$ unless $\tau \ll h^2$ (checked §7 E: with $\tau = 10^{-6}$ the error is 1.2e-4 at $h=10^{-4}$ but 1.9e-2 at $h=10^{-5}$, where the predictor gives 1.2e-5). (P) prescribes exact values, so its only noise is floating-point. (P) also reproduces the time grid by construction (no global Newton, so no global-convergence cutbacks), and gives the free diagnostic $r_F(u^* + h\hat s, \ldots) = O(h^2)$ (**predictor consistency test**; $O(h)$ if $K$ or $p$ is wrong). (P) propagates errors in $\hat s_j$ into the history (Remark 4), which (E) does not; that is benign at the stated orders. It also requires the lockstep schedule of §4.4.

**Specification:** use (P) for computation. Use (E), with a tightened tolerance and fixed incrementation, only as an independent full-FD reference.

## 2. Constrained coordinates

### 2.1 Prescribed DOFs (Abaqus *BOUNDARY) [exact]
At increment $i$ the equations are $r_{F,i} = 0$ ($|F|$ equations) with $u_{C,i} = g_i(a)$. The rows $r_{C,i} = -RF_{C,i}$ only *define* the unknown reactions. Differentiating the $F$ rows, with $K_{FC} = -\partial r_F/\partial u_C$:
$$K_{FF,i}\, s_{F,i} = p_{F,i} - K_{FC,i}\, s_{C,i}, \qquad s_{C,i} = g_i'(a).$$
In $p_{F,i}$ the previous sensitivity $s_{i-1}$ is the **full** vector, including $s_{C,i-1} = g_{i-1}'$. A parameter-dependent BC (amplitude value, prescribed magnitude, geometry-driven target) has $s_C \ne 0$; setting $s_C = 0$ is wrong.

Two equivalent probe forms (both checked to 1e-59, §7 A):
- **Form A (all current DOFs frozen):** the probe holds $u_C = g_i(a)$ (nominal). Then $\mathcal D_F \to p_F$ and $K_{FF}s_F = \mathcal D_F - K_{FC} s_C$. Requires the $K_{FC}$ columns.
- **Form B (BCs at their perturbed values):** the probe holds $u_F = u_F^*$ and $u_C = g_i(a+h)$. Then $\mathcal D^B_F = p_F - K_{FC}s_C + O(h)$, so $K_{FF}s_F = \mathcal D^B_F$. No $K_{FC}$ needed; the commit and probe use the same BC values; it extends to all orders with exact $g(a+h)$ (§4.3).

**Recommendation:** use Form B as the production path. Use Form A as a cross-check wherever $K_{FC}$ is available. Whether Abaqus operator output retains BC columns is **H-K1**.

### 2.2 Reactions on $C$ [exact]
$RF_C = -r_C$ **[H-RF]**. Its sensitivity is $dRF_C/da = K_{CF}s_F + K_{CC}s_C - p_C$ (Form A), or $= K_{CF}s_F - \mathcal D^B_C$ (Form B). It is computed more simply, without the $K_{C\cdot}$ blocks, as an output field on the commit branch (§5): $[RF_C(+h) - RF_C(-h)]/(2h) + O(h^2)$. On the commit branch, $RF_F = -r_F(\text{predictor}) = O(h^2)$, which is the consistency residual and not a physical reaction. **$RF_C$ is never needed to compute $s_F$:** the $C$ rows only contain the extra unknowns $RF_C$.

### 2.3 Linear MPC / tie / *EQUATION: $u_D = T u_I + g_D(a)$ [exact]
Write $u = P v + \hat g$ with $v = u_I$, $P = \begin{bmatrix} I \\ T\end{bmatrix}$, $\hat g = \begin{bmatrix} 0 \\ g_D \end{bmatrix}$ (after DOF permutation). The constraint $c(u) = u_D - T u_I - g_D$ has $B = [-T,\; I]$ and $BP = 0$, so the constraint forces $B^\top\lambda$ are annihilated by $P^\top$. The reduced residual is
$$\rho(v, \text{hist}, a) := P(a)^\top\, r\big(P(a) v + \hat g(a), \text{hist}, a\big),$$
the reduced equilibrium is $\rho_{F} = 0$ on independent free DOFs, $v_C = g_C(a)$ on independent prescribed DOFs, and $\hat K := -\partial\rho/\partial v = P^\top K P$ (for $T$ constant: $\hat K = K_{II} + K_{ID}T + T^\top K_{DI} + T^\top K_{DD} T$).

- **Constant $T$, Form A** (all of $u$ frozen at $u^*$; $p$ the full-vector pseudoload): $\hat K_{FF}\, s_{v,F} = \big[P^\top (p - K\hat g')\big]_F - \hat K_{FC}\, s_{v,C}$. Then $s_u = P s_v + \hat g'$; the reduced pseudoload is $P^\top p$.
- **Parameter-dependent $T(a)$** (e.g. geometry-dependent tie weights): extra terms $-P^\top K P' v + P'^\top r$. Note $P'^\top r \neq 0$ in general because $r = -B^\top\lambda \ne 0$ at equilibrium. Then $s_u = P s_v + P' v + \hat g'$.
- **Form B on $\rho$ (recommended):** $\rho$ is just another residual in the coordinates $v$, so Theorem 1 and §2.1 apply verbatim. With the oracle enforcing the constraint at $a+h$ (so it uses $T(a+h)$ and $g_D(a+h)$) and prescribing only $v$: $\hat K_{FF}s_{v,F} = \lim[\rho_F(v_F^*, g_C(a+h), \text{hist}(h), a+h) - \rho_F(v_F^*, g_C(a), \text{hist}(0), a)]/h$. Every $T', g_D'$ term is included automatically, and $T$ need not be known (TIE weights are internal to Abaqus). $\hat K$ is still needed: either Abaqus supplies the reduced operator (**H-K2**), $P^\top K P$ is formed from an explicit $T$, or it is approximated by oracle directional differences.
- **Nonlinear constraints** (finite-rotation coupling, BEAM-type MPCs) are not covered. They are only linearizable, with $P = \partial u/\partial v$ state-dependent, and are flagged unsupported until validated.

**Which RF components equal $-r$** (under H-RF, oracle prescribing all independent DOFs, constraints active):
1. Independent DOFs that were originally free: $RF_{v,F} = -\rho_F = -(r_F + T_{\cdot F}^\top r_D)$. This includes constraint force transmitted from dependent DOFs and loads applied on dependent DOFs. For DOFs in no constraint it is simply $-r_F$. **These rows are the only rows used for $s$.**
2. Independent DOFs that were originally prescribed: $RF_{v,C} = -\rho_C$, the physical reaction. Used only for reaction sensitivity outputs.
3. Dependent DOFs: must **not** be prescribed in the oracle (that over-constrains or conflicts with the MPC). Whatever Abaqus reports there (constraint force, zero, or nothing) is not used (**H-RF-D**).

Alternative when $T$ is explicit (*EQUATION): drop the constraint, prescribe all of $u = Pv + \hat g$, read the full $-r$, and reduce by $P^\top$ in ABSS. Running both variants is a strong cross-check.

## 3. The reaction-force oracle

**Oracle job $\mathcal O_i(\tilde u; \text{branch})$:** restart from the branch state committed at $t_{i-1}$ (model already defined with the branch parameter from $t_0$). Run one increment $[t_{i-1}, t_i]$ with identical $\Delta t_i$ and total time (amplitudes evaluated at the same total time). Keep all original loads (CLOAD/DLOAD/DSLOAD, follower, pressure), with identical amplitudes, and all constraints. Prescribe **every independent DOF**: originally-free ones at $\tilde u_F$, originally-prescribed ones at their (Form A/B) values.

**Proposition 3 [exact given H-RF; the Abaqus part is hypothesis].** With no unknown DOFs left, the increment's equilibrium iteration reduces to evaluating the state update $\tilde q_i = Q_i(\tilde u, \ldots)$ and the forces at $\tilde u$. Abaqus' own equilibrium at a held DOF reads $F^{int} = F^{ext} + RF$, so $RF_{v} = -\rho(\tilde u)$ on all held independent DOFs, sign included. Hence $r_F$ (reduced: $\rho_F$) $= -RF_F$, and loads that sit on originally-prescribed DOFs end up in $RF_C$ and never enter $r_F$.

Hypotheses that must be validated before relying on this (decisive gates of spec §7):
- **H-RF:** RF on a DOF that carries both a *BOUNDARY and a *CLOAD/DLOAD contribution equals $F^{int}-F^{ext}$ *including* that load (loads are not dropped at held DOFs). Test: a 1-DOF spring with load $F$ held at $\tilde u$ must give $RF = k\tilde u - F$.
- **H-ONE-INC:** the oracle increment is not subdivided (UMAT `PNEWDT<1`, distortion and contact cutbacks), and the iteration count and $\Delta t$ are logged and checked. A subdivided oracle evaluates a different map $Q$ and must be rejected.
- **H-RST:** restart/replay reproduces $q_{i-1}$ bit-for-bit (or to $\ll h\,\|w\|$) relative to an uninterrupted run.
- **H-K:** $K_i$ from operator output equals $-\partial r_i/\partial u_i$ at the converged state with history frozen. Check $K v \approx -[r(u^*+\varepsilon v) - r(u^*-\varepsilon v)]/(2\varepsilon)$ by two oracle probes on the nominal replay branch.

## 4. Higher order

### 4.1 Theorem 2 (order-$m$ recursion) [exact; A2 with k = K, A3]
Let $U_i(h) := u_i(a+h) = \sum_m \frac{h^m}{m!}u_i^{(m)}$ be the true branch and $U_i^{[<m]}(h) := \sum_{j=0}^{m-1}\frac{h^j}{j!}u_i^{(j)}$, $U_i^{[\le L]}$ analogously. Suppose the history at $i-1$ is **order-$L$ correct**, $\tilde u_{j}(h) - U_{j}(h) = O(h^{L+1})$ for $j<i$, with $m \le L$. Define the order-$m$ probe
$$y_i^{(m)}(h) := r_{F,i}\big(U_{F,i}^{[<m]}(h),\; g_{C,i}(a+h),\; \tilde u_{i-1}(h),\; \tilde q_{i-1}(h),\; a+h\big)\quad\text{(Form B)}.$$
Then $y_i^{(m)}(h) = \frac{h^m}{m!} K_{FF,i}\, u_{F,i}^{(m)} + O(h^{m+1})$, hence
$$\boxed{\,K_{FF,i}\,u_{F,i}^{(m)} = m!\,[h^m]\,y_i^{(m)}(h),\qquad [h^j]\,y_i^{(m)} = 0 \ (1\le j<m).}$$
*Proof.* As in the Lemma of §1.2, but to order $L$: $\tilde q_{j} - Q_j(h) = O(h^{L+1})$ (Taylor of $Q_j$ to order $L$, induction). Write $U^{[<m]}_F = U_F - \delta$ with $\delta = \frac{h^m}{m!}u_F^{(m)} + O(h^{m+1})$. Then $0 = r_F(U_F, g_C(a+h), \text{true hist}, a+h)$ and
$y^{(m)} = r_F(U_F - \delta, \ldots) + O(h^{L+1}) = -R^u_{FF}(U(h))\,\delta + O(\|\delta\|^2) + O(h^{L+1}) = K_{FF}\frac{h^m}{m!}u_F^{(m)} + O(h^{m+1})$, using $R^u(U(h)) = R^u(u^*)+O(h)$, $2m \ge m+1$ and $L+1 \ge m+1$. ∎

The sign under $K = -\partial r/\partial u$ is **plus**. The case $m=1$ is $K s = p$ (Theorem 1).

### 4.2 What the history branch must contain [exact; counterexample checked]
$[h^m]\,y^{(m)}$ depends on the history Taylor coefficients **through order $m$ inclusive**. A history defect $\frac{h^m}{m!}\epsilon_j$ changes $[h^m]y^{(m)}$ by $\frac1{m!}(R^{u'}\epsilon_{i-1} + R^q\,\eta_{i-1})$, with $\eta$ the propagated $q$-defect. In general this is nonzero. Therefore:

- To compute orders $1..K$, every branch must commit $\tilde u_j(h) = U_j^{[\le K]}(h)$, i.e. the **order-$K$-complete** predictor that includes $u_j^{(K)}$. An order-$(K-1)$ history is insufficient. Checked (§7 B): with a history of order $L$, orders $\le L$ are exact and order $L+1$ is wrong by 1.5–2.3%.
- This is feasible because the march is increment by increment, so $u_j^{(K)}$ for $j<i$ is already known when increment $i$ is processed.
- One branch per offset, committed at order $K$, serves **all** orders $m\le K$. Committing more than order $m$ does not disturb $[h^m]$.
- Prescribed DOFs in commits: exact $g_j(a+h)$ (correct to all orders). Initial state: $u_0(a+h), q_0(a+h)$ as defined by the perturbed input.
- A re-equilibrated branch (E) is correct to all orders in exact arithmetic but carries the $\tau/h^m$ tolerance error. It is unusable for $m\ge2$ in practice.

### 4.3 Prescribed DOFs at order $m$ [exact; checked]
Form B uses $u_C = g_{C,i}(a+h)$ exactly, as in 4.1. Form A holds $u_C = g^{[<m]}_{C,i}(h)$ (the Taylor polynomial without the order-$m$ term) and solves
$$K_{FF}u_F^{(m)} = m!\,[h^m]\,y_A^{(m)} - K_{FC}\, g_C^{(m)},\qquad g_C^{(m)} = d^m g_C/da^m .$$
The two forms agree to 1e-59 in §7 A. For constraints, replace $r_F \to \rho_F$ and $K_{FF}\to\hat K_{FF}$ (§2.3); Form B with Abaqus enforcing the constraint at $a+h$ includes all $d^mT/da^m$, $d^m g_D/da^m$ terms.

### 4.4 Lockstep algorithm (implementer form)
Offsets $h_l = \beta_l h$, $l = 1..L_o$, plus node $h_0 = 0$ (nominal replay branch). Every node has its own branch run from $t_0$ with parameter $a + h_l$.
```
for i = 1..n:
  K = K_FF,i (factorize once; reuse for all m and all parameters)
  for m = 1..K_order:
    for each node l (incl. 0): y_l = Oracle_i( U_F^[<m](h_l), g_C(a+h_l) ; branch l at i-1 )   # probe, no commit
    c = polyfit(nodes h_l, values y_l)                 # §4.5
    solve K u_F^(m) = m! c_m ;  diagnostics: |c_j|, 1<=j<m  (should be ~0)
  for each node l: Commit_i( U^[<=K](h_l), g_C(a+h_l) ) on branch l      # advances history
  log predictor-consistency residual  RF_F(commit) = O(h^{K+1})
```
Cost per parameter direction and increment: $(L_o+1)\,K$ probes + $(L_o+1)$ commits. The node-0 branch is shared by all parameters. The probes of order $m$ need $u_i^{(m-1)}$ from all nodes, so the branches must stay synchronized at each $(i,m)$.

### 4.5 Extracting $[h^m]$ from finite offsets [approx; checked]
Fit $y(h) \approx \sum_{j=0}^{d} c_j h^j$ through the $d+1 = L_o+1$ nodes (Vandermonde solve; least squares if there are more nodes). Then:
- **Truncation:** $c_m - [h^m]y = O(h^{d+1-m})$. Symmetric node sets cancel by parity: $\{0,\pm h\}$ gives $c_1, c_2$ at $O(h^2)$; $\{0,\pm h,\pm2h\}$ gives $c_1,c_2$ at $O(h^4)$ and $c_3$ at $O(h^2)$ (checked §7 D: errors scale exactly so).
- **Noise:** absolute noise $\eta$ in $y$ gives an error $\approx \eta\,\|e_m^\top V^{-1}\|\sim C_m\eta/h^m$. Optimal $h \sim (\eta/A)^{1/(p+m)}$; ABSS must run an $h$-sweep and report the plateau.
- **Where $\eta$ comes from (checked §7 F):** relative rounding of the *reported* residual is benign, because RF is the small imbalance itself (error stays ~1e-7). Rounding of the *prescribed displacement values written into the inputs* is catastrophic: at 7 significant digits the second-order error is 1.6e-2 at $h=10^{-2}$ and order 3 is useless. **ABSS must write every prescribed value with 17 significant digits** (round-trip double) and use the *same* $u^*$ representation on every node. Even with 17 digits, order 2 degrades below $h\approx10^{-3}$ (3.2e-8 at $10^{-4}$, 3.2e-6 at $10^{-5}$) and order 3 below $h\approx10^{-3}$ (1.6e-4 at $10^{-4}$) in the test model, with $h$ relative to $a_0 = 1.3$. Abaqus-internal noise (local Newton in UMAT return mapping, contact tolerances) can be far larger and is unknown a priori.
- **Diagnostics:** the fitted lower coefficients $c_1..c_{m-1}$ should vanish relative to $c_m h^{m}$ scales. This generalizes the predictor consistency test and flags a wrong $K$, wrong lower orders, or nonsmoothness. A constrained fit that forces them to 0 is optional, and only after the diagnostic passes.

### 4.6 Mixed derivatives via polarization [exact]
For a parameter vector $\mathbf a$ and a direction $\mathbf d$, run the whole machinery with $a(h) = \mathbf a + h\mathbf d$, perturbing all parameters jointly in each branch input. This yields the directional derivatives $D^m_{\mathbf d}u = \sum_{|\alpha|=m}\frac{m!}{\alpha!}\mathbf d^\alpha\partial^\alpha u$. Mixed partials follow from the symmetric-multilinear polarization identity:
$$\partial^m u[\mathbf v_1,\ldots,\mathbf v_m] = \frac{1}{2^m m!}\sum_{\varepsilon\in\{\pm1\}^m}\Big(\prod_k\varepsilon_k\Big)\,D^m_{\sum_k\varepsilon_k\mathbf v_k}u,$$
with parity halving the number of distinct directions. Second order: $\partial_{a_j}\partial_{a_l}u = \tfrac14\big(D^2_{e_j+e_l} - D^2_{e_j-e_l}\big)$, or $\tfrac12\big(D^2_{e_j+e_l} - D^2_{e_j} - D^2_{e_l}\big)$ reusing the pure ones. Parameters must be nondimensionalized (scaled by nominal magnitude or a user scale) before forming directions. Cancellation amplifies directional errors by up to $\sim 2^{m}$, so mixed results carry their own uncertainty and must be labelled separately from pure ones. First-order mixed derivatives need nothing extra, because first derivatives are linear in $\mathbf d$.

### 4.7 Approximate tangent: oracle-only defect correction [derived; checked on model only]
Abaqus converges with an approximate Jacobian (a non-consistent UMAT DDSDDE, contact regularization), but the linear sensitivity solve does not tolerate one. At the current increment, with the same branch history:
$r_F(u^* \pm h\hat s, \ldots)$ gives $\frac{r(+h)-r(-h)}{2h} = p - K_{true}\hat s + O(h^2)$. The iteration $\hat s \leftarrow \hat s + K_{approx}^{-1}\,\frac{r(+h)-r(-h)}{2h}$ therefore converges linearly when $\rho(I - K_{approx}^{-1}K_{true}) < 1$. Checked (§7 G): with $K$ scaled by 1.5 the error goes 0.34 → 3.5e-11 in 30 corrections, at a rate of 1/3. Each correction costs one probe per node. A first-order commit residual that scales as $O(h)$ rather than $O(h^2)$ is the detector for this situation.

## 5. Output-field sensitivities

An output at a Gauss/section point, $y_i = Y_i(u_i, u_{i-1}, q_{i-1}, a)$ (S, E, LE, PE, PEEQ, SDV, energies, RF), is evaluated on the **commit** branches, i.e. with current displacement $U_i^{[\le K]}(h_l)$ and order-$K$ history. Then $\tilde y_i(h) = y_i(a+h) + O(h^{K+1})$ and
$$d^m y_i/da^m = m!\,[h^m]\,\tilde y_i(h), \quad m \le K,$$
using the same fit of §4.5 (node 0 = nominal replay). Checked §7 C to 1e-60 for $K=3$. First order: $(\tilde y(+h)-\tilde y(-h))/(2h) + O(h^2)$. Note:
- Do **not** evaluate outputs on the probe (frozen $u^*$) branch. That gives a partial derivative and misses the $\partial_u Y\, s_i$ term.
- Do not use $dU/da$ in place of $dS/da$. Compare identical instance/element/IP/section point at identical $t_i$.
- **Invariants:** differentiate the invariant, not the tensor sensitivity. For Mises $f=\sqrt{\tfrac32 s{:}s}$ with $s=\operatorname{dev}\sigma$: $f' = \tfrac{3}{2}\, s{:}\sigma'/f$ and $f'' = \big[3(s'{:}s' + s{:}s'') - 2f'^2\big]/(2f)$. Equivalently, take the FD/fit of $f(\tilde\sigma(h_l))$. Both are acceptable; the chain rule on fitted tensor jets is less noisy. $f(\sigma')\neq f'$ in general. **Non-differentiable at $s=0$:** $f(\sigma^*+h\sigma') = |h|f(\sigma') + O(h^2)$, so the one-sided derivatives are $\pm f(\sigma')$, a centred FD returns ~0, and $f''\sim 1/f$ blows up as $f\to0$. Flag a point when $f^* \lesssim |h_{max}|\,\|\sigma'\|$ (the stencil crosses the cone tip) or when $f^*$ is below a relative floor. The same holds for principal values at repeated eigenvalues, magnitudes at zero, and PEEQ at yield onset.
- **Frames:** components reported in local/corotational frames (orientations, shells, NLGEOM) differentiate as components in a frame that may itself depend on $a$. Store the frame. For a fixed-frame tensor derivative, rotate each branch's values to global first and then differentiate. Invariants are frame-free.

**Geometry parameters.** $X(a)$ are the reference nodal coordinates, the primary unknown stays the displacement $u$, and $x = X(a) + u$. Every branch input has nodes at $X(a+h_l)$. Probes freeze $u$ (not $x$) at the predictor, so $\partial_X r\,X'$ (stiffness, load area and direction, follower loads) lands in the pseudoload automatically. Report $s = du/da$ and $dx/da = X' + s$. A BC that fixes an absolute position has $g_C(a) = x_{target} - X_C(a)$, so $g_C' = -X_C'$. ABSS must ask the user or infer explicitly whether a BC means "displacement" or "position". IP outputs are material (fixed element/IP index) derivatives, and the IP location moves by $dx_{IP}/da$. Node/element correspondence and positive Jacobians are mandatory, and remeshing is unsupported. Rotational DOFs: the Taylor predictor and the derivatives are in the coordinates Abaqus uses for prescribed UR (**H-UR**: whether a prescribed UR under NLGEOM is a total rotation vector); finite rotations are not additive.

## 6. Limitations (what the derivation does not establish)

1. **Nonsmoothness (yield onset or reversal, contact open/close, stick/slip, damage).** Outside A2, $p_i$ may not exist. If a branch switches the active set relative to nominal at some increment, $\mathcal D_i$ has an $O(1)$ error there and $O(1)$ history errors afterwards. A switch is guaranteed once $|h| \gtrsim$ distance-to-switch $/\,|$rate$|$. Detect this by: active-flag comparison across nodes (PEEQ increments, contact status), failure of the $h$-sweep to show the expected order, nonvanishing lower fit coefficients, and an $O(h)$ commit residual. Report it, never smooth it. One-sided (directional) derivatives exist for many piecewise-smooth maps, but they are not implemented and must not be presented as derivatives.
2. **Bifurcation and limit points.** $K_{FF}$ becomes singular (A3 fails), so $s$ is unbounded or non-unique. Monitor the condition estimate and pivots, and refuse to report beyond a threshold.
3. **Cutbacks and the time grid.** The derivative is that of the algorithm on the frozen nominal grid. Adaptive incrementation is discontinuous in $a$, so full-FD references with automatic incrementation are not comparable; they must use the same fixed grid. Oracle/commit subdivision (H-ONE-INC) invalidates the increment.
4. **Solver tolerance.** $u^*$ satisfies $\|r\|\le\tau$, not $=0$. The node-0 probe cancels the offset. The linearization point error is $O(\|K^{-1}\|\tau)$, giving a relative error of the same order in $s$ (acceptable). Full re-solve references carry an error of order $\tau/h^m$ (§1.3), so their tolerance must be tightened.
5. **Floating point and internal iteration noise** limit usable orders (§4.5). Order $\ge3$ is likely unreliable on real models with local constitutive iterations, and stays experimental until $h$-sweeps show a plateau.
6. **Tangent quality** (A5): a wrong $K$ gives wrong $s$ even though Abaqus converged. Gate with H-K, or use §4.7.
7. **Not covered:** dynamics (needs an effective tangent and inertial history), multiphysics, nonlinear MPCs, explicit, remeshing, history-dependent external files, and nondeterministic user subroutines (violate A4).
8. The 2-DOF check exercises the algebra of the recursion, the history requirement and the extraction. It says nothing about Abaqus' RF semantics, restart fidelity, or operator output (H-*). Those need the Abaqus gates of spec §7.
